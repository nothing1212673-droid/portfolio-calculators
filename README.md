# Interactive Calculator Portfolio Demos

Two standalone, responsive HTML/CSS/JavaScript projects for fictional brands. All prices and timelines are illustrative examples, not commercial offers.

| Project | Live calculator | Presentation view |
| --- | --- | --- |
| NEXUS Logistics | [Shipping cost calculator](https://nothing1212673-droid.github.io/portfolio-calculators/shipping-calculator/) | [1280 × 720 view](https://nothing1212673-droid.github.io/portfolio-calculators/shipping-calculator/presentation.html) |
| BUILDORA Construction | [Construction cost calculator](https://nothing1212673-droid.github.io/portfolio-calculators/construction-calculator/) | [1280 × 720 view](https://nothing1212673-droid.github.io/portfolio-calculators/construction-calculator/presentation.html) |

Open [the collection homepage](https://nothing1212673-droid.github.io/portfolio-calculators/) to explore both.

## Run locally

Download the repository and open either calculator's `index.html` in a browser. No installation, server or API key is required. Each calculator has its own README with the sample rate model.
